# BrightSmile CRM & Workflow Automation Demo

A foundational GoHighLevel (GHL) portfolio project demonstrating CRM organization, lead intake, missing-information review, opportunity handling, and staff follow-up task creation in a fictional dental-clinic scenario.

> **Portfolio disclosure:** BrightSmile is fictional. This repository contains sanitized demo documentation and selected screenshots. It is not a live clinic deployment or a compliance assessment.

## What this demonstrates

- Lead intake workflow structure and trigger configuration.
- Missing-information branch logic and classification tags.
- CRM pipeline organization and opportunity tracking.
- Workflow execution-log review.
- Follow-up task workflow evidence.
- Test-case documentation with limitations stated honestly.

## Evidence

The `evidence/` folder contains the six original screenshot captures, preserved at their source resolution. The sanitized workbook in `documentation/` contains workflow logic and test notes; demo lead names, sample email references, and long identifiers have been generalized for public sharing.

## Safety and scope

- Screenshots and workbook are for a fictional portfolio scenario.
- Raw audit-log exports, raw opportunity exports, and unrelated account-level captures are intentionally excluded.
- Tests document observed scenarios only; they do not guarantee production reliability or compliance.

## Folder map

- `evidence/` — workflow builder, pipeline, and execution-log screenshots.
- `documentation/` — sanitized workbook with pipeline, field, workflow, and test-case notes.
